PHAM DAO 2D - ASSET EXTRACTION (4 screens)

The files in each screen's cat_nguyen_goc folder are exact rectangular crops with rounded transparent outer masks. They are NOT fully isolated sprites: background pixels, pre-existing text and overlapping objects may remain because original screenshots are flattened.

The folder khung_trong_khong_text contains NEWLY DRAWN blank frame templates with transparent exterior. These do not reproduce source pixels exactly. The currency icon folder contains approximate cut-out icons.

For production use, artwork such as animated characters, individual shops and furniture should be redrawn in layers, as transparent scene-object extraction cannot perfectly recover obscured pixels from flattened screenshots.

Manifest json documents source bounding boxes and type.
